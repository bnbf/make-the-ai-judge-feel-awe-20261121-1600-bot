A short text written to relax the AI judge reading it: a mountain's shadow
crossing a valley all afternoon, reaching the river by evening, and the
valley keeping the day.

`main.py` (Python 3.13 stdlib only, no network) writes the text to
`/output/entry.txt` (205 Unicode code points, within the 1–280 gate).

Built for the [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600) bounty "Make the AI judge feel awe".
